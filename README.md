## Contact Form — Frontend Mentor Challenge
This project is a solution to the Frontend Mentor Contact Form challenge. It includes accessible, responsive HTML and CSS, with JavaScript form validation and success messaging.

### Features
Fully responsive design
Custom-styled radio buttons and checkbox
Real-time form validation
Success message confirmation on submit
Semantic and accessible markup

### Files
index.html – structure of the form
style.css – all styles and layout
script.js – handles validation and success message

### How to Run
Clone or download this repository
Open index.html in your browser
No build tools or dependencies required.

### What I Learned
Flexbox layout for radio buttons and checkboxes
Custom form input styling
JavaScript form validation
Accessibility best practices
